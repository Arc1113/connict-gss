# Connict GSS Troubleshooting

Open Connict GSS first and check the System Status screen.

- **Database needs attention:** choose restart once. If it stays unavailable, do not reinstall or delete data; export diagnostics and contact support.
- **Live updates need attention:** restart Connict GSS. Browsers recover current stage state over HTTPS after reconnecting.
- **Announcement engine needs attention:** ceremony operations remain available. Use the live-announcer or approved manual-audio fallback.
- **Devices cannot connect:** confirm all devices are on the same private network and use the current HTTPS server address.
- **Upgrade stopped:** the installer has retained application data and a verified backup. Export diagnostics before retrying.

Support diagnostics must not include passwords, QR tokens, encryption keys, student records, or raw database files.

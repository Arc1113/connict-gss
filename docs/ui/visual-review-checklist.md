# Visual Review Checklist

Use the real authenticated routes and realistic data. Save evidence for the
required viewports.

## Hierarchy and content

- [ ] One purpose is visually dominant.
- [ ] Critical information appears before supporting information.
- [ ] Labels are concise and sentence case.
- [ ] Recovery text is specific.
- [ ] No fake metric, chart, marketing copy, or unrelated panel appears.
- [ ] Long names/programs wrap naturally.
- [ ] Missing optional content leaves no awkward gap.

## Layout

- [ ] Alignment is deliberate.
- [ ] Related items share spacing.
- [ ] Section boundaries do not depend on nested cards.
- [ ] No horizontal overflow.
- [ ] Required content fits the viewport or uses approved page scrolling.
- [ ] Focus rings are visible and unclipped.
- [ ] Controls meet target-size guidance.

## Visual system

- [ ] Colors use documented semantic roles.
- [ ] Essential status does not depend on color.
- [ ] Borders/radius/shadow are restrained.
- [ ] No decorative gradient, glow, glass effect, or excessive pill appears.
- [ ] Typography remains readable at the target distance/device.
- [ ] Motion is purposeful and reduced-motion safe.

## Scanner states

- [ ] Ready
- [ ] Processing
- [ ] Success
- [ ] Invalid
- [ ] Duplicate/completed
- [ ] Ineligible or honestly documented test limitation
- [ ] Ceremony inactive
- [ ] Server request failed
- [ ] Reverb disconnected
- [ ] Reconnected
- [ ] Missing information
- [ ] Long name

## Stage states

- [ ] Loading
- [ ] Idle
- [ ] Presented
- [ ] Long name/program
- [ ] Missing photo
- [ ] Missing honors
- [ ] Missing audio
- [ ] Disconnected without technical warning
- [ ] HTTP recovered
- [ ] Cleared

## Anti–AI-slop final pass

- [ ] No equal card grid drives hierarchy.
- [ ] No cards inside cards.
- [ ] No oversized marketing heading.
- [ ] No unnecessary icon beside each heading.
- [ ] No ordinary label is styled as a badge without reason.
- [ ] No audience-facing operator/technical UI remains.
